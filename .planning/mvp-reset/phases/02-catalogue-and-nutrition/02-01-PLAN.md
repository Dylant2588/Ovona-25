<interfaces>
Existing RecipeMacros = { calories: number; protein: number; carbs: number; fat: number }.
RecipeIngredient.amount is the entire recipe's quantity; RecipeRecord.servings is the divisor; RecipeRecord.macros is one serving. validateMealAgainstRecipe rounds each per-serving macro times portionMultiplier to integers. Keep that behavior.

Define and export the following contracts in types.ts; field names are the cross-plan contract:
- FoodState = "raw" | "cooked" | "drained" | "as_sold".
- FoodCompositionSnapshot: { id: string; revision: string; name: string; state: FoodState; basis: { amount: number; unit: "g" | "ml" | "each" }; macros: RecipeMacros; source: { publisher: string; dataset: string; version: string; reference: string; retrievedAt: string; licence: string; foodCode: string } }.
- QuantityConversionEvidence: { densityGramsPerMl?: number; gramsPerUnit?: { unit: "each" | "large" | "piece"; grams: number }; mlPerUnit?: { unit: "tbsp" | "tsp"; ml: number }; reference: string }.
- IngredientNutritionEvidence: { food: FoodCompositionSnapshot; quantityState: FoodState; mappingReference: string; conversion?: QuantityConversionEvidence }.
- RecipeIngredient.nutrition?: IngredientNutritionEvidence.
- CalculatedNutritionEvidence: { policyVersion: "ingredient-v1"; servings: number; batchMacros: RecipeMacros; perServingMacros: RecipeMacros; lines: Array<{ ingredientIndex: number; foodId: string; foodRevision: string; sourceAmount: number; sourceUnit: "g" | "ml" | "each"; macros: RecipeMacros }> }.
- Extend existing RecipeRecord.nutrition with calculation?: CalculatedNutritionEvidence. New calculated records use method "ingredient_calculated_v1"; existing methods remain legacy evidence.
- calculateRecipeNutrition(recipe: unknown): { ok: true; calculation: CalculatedNutritionEvidence } | { ok: false; errors: string[] }.
- calculatedNutritionErrors(recipe: unknown): string[] checks a claimed calculated method against recomputation; legacy methods return no calculated errors.
- newApprovalNutritionErrors(recipe: unknown): string[] rejects every new approval without valid ingredient_calculated_v1 evidence.

The core module must not import repository.ts, approval.ts or Supabase, avoiding validation import cycles. Never derive nutrient IDs from canonicalId.
</interfaces>
