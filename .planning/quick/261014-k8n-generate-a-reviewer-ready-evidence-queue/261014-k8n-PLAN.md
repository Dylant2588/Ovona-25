# Recipe evidence review queue

Generate a read-only, reviewer-ready inventory from pending Supabase recipe
drafts. It must distinguish evidence that needs human verification from a
recipe's claimed data and must not approve or mutate any recipe.

## Verification

- Script rejects missing administrator configuration.
- Run against the hosted pending-draft library and verify the queue count.
